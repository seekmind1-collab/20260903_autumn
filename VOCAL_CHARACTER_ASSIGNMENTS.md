# VOCAL CHARACTER ASSIGNMENTS — 2026 AUTUMN

## 목적

Track 001~100의 기존 `Female / Male / Duet` 배치를 유지하면서 실제 제작 단계에서 사용할 Vocal Character를 최종 관리합니다.

이 문서는 `VOCAL_CHARACTER_GUIDE.md`의 조합형 기준을 적용한 프로젝트 전용 단일 배치표입니다.

- 기존 MASTER BOARD의 Title / 상황 / 관계 / 감정 / Primary Genre / BPM / Vocal Type / Language / Idol Style / Structure는 변경하지 않습니다.
- 사용자 별도 승인 전 Track Status는 계속 `PLANNED`로 유지합니다.
- 아래 Character는 완성 Style Prompt가 아닙니다.
- 실제 작사 세션에서는 이 배치표에서 곡의 핵심 특성 1~2개와 필요한 기능적 설명만 추려 Style Prompt로 확장합니다.
- Character 표기 순서는 기본적으로 `Timbre / Weight / Register / Delivery / Expression`입니다.
- Technique는 필요한 Track에만 지정합니다.
- Duet은 `Voice A / Voice B`의 대비와 Role Configuration을 함께 관리하며, MASTER BOARD에서 성별이 명시되지 않은 경우 임의로 성별을 추가하지 않습니다.

## 전체 다양성 QA

### Female

- `airy / high`를 기본값으로 사용하지 않습니다.
- 저·중저역 배치 예: 003, 017, 034, 036, 057, 059, 069, 076, 079, 091.
- husky 계열은 019, 036, 050처럼 Weight / Delivery / Expression을 달리해 사용합니다.
- bright/idol 계열도 모두 동일한 `clear + light + high`로 만들지 않습니다.

### Male

- `low / husky`를 기본값으로 사용하지 않습니다.
- silky, clear, raspy, velvety, earthy, warm, crisp 계열을 분산합니다.
- mid-high/high는 006, 008, 031, 035, 046, 049, 065, 075, 078, 085, 089 등 활력·리듬 곡에 적극 사용합니다.

### Technique

- controlled belting은 일부 피크형 곡에만 제한합니다.
- light falsetto는 필요한 곡에만 제한합니다.
- excessive breathiness, exaggerated melisma, constant high belting은 사용하지 않습니다.

### Duet

- Vocal Type `Duet`만 반복하지 않고 Voice Contrast와 Role을 함께 분산합니다.
- Alternating Verses / Call and Response / Equal Duet / Unison Chorus / Shared Final Chorus / Atmospheric Backing 등을 곡의 관계와 Hook에 맞게 나눕니다.

## 실제 제작 단계 적용 규칙

1. 대상 Track의 MASTER BOARD 행을 확인합니다.
2. 이 파일에서 동일 Track의 확정 Vocal Character를 확인합니다.
3. `VOCAL_CHARACTER_GUIDE.md` 기준으로 핵심 음색/표현 특성 1~2개를 우선 선택합니다.
4. Register / Delivery / Technique는 필요한 기능적 정보만 추가합니다.
5. Character 전체를 그대로 Style Prompt에 나열하지 않습니다.
6. 앞뒤 Track의 Character와 다시 비교해 실제 생성 단계에서도 연속 피로를 확인합니다.
7. 사용자 승인 전 Track Status는 `PLANNED`를 유지합니다.
